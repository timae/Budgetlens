Budget Lens

Drop bank exports or budget sheets and see where the money goes, how it compares to budget and how it changes over time.

Processed locally · nothing uploaded
Up to 12 files, 15 MB each. Nothing leaves this browser tab.

Amounts are never converted between currencies.

Private by design. Files are read and analysed in this tab. The server only serves static files; it has no upload endpoint, database or storage, and the page's security policy blocks all network requests.

Nothing is saved in the browser. Use Save settings to keep accounts, people, fixed costs, budgets and rules in a file of your own. Currencies are never converted.
